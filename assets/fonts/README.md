Place Montserrat font files here.

Required files (exact names used by CSS):
- Montserrat-Light.ttf   (weight 300)
- Montserrat-Regular.ttf (weight 400)

How to obtain:
- Download Montserrat from Google Fonts (choose TTF) or copy your licensed local files.

Purpose:
- These fonts are used by the preview and by the HTML-to-PDF export so both use the exact same typeface.

After adding the .ttf files, re-run the build: npm run build
