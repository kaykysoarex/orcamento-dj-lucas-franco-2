# Fotos dos DJs para a proposta

Adicione aqui somente as fotos reais e otimizadas, em WebP:

- `dj-lucas-franco.webp`
- `dj-felipe-souza.webp`

Depois de incluir cada foto, atualize o respectivo perfil em
`src/config/djProfiles.js`: preencha os contatos públicos reais e marque
`imageAvailable` como `true`. A página individual e a exportação só são
habilitadas quando todas essas informações existirem.
